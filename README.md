# 🎵 Chord Annotator

A beautiful, mobile-first web application for annotating song lyrics with music chords. Perfect for musicians who want to organize their chord charts with color-coded visual aids.

## ✨ Features

- **📝 Create & Manage Songs**: Add unlimited songs with titles, artists, and lyrics
- **🎸 Easy Chord Annotation**: Select any text (even mid-word) and assign chords
- **🌈 Color-Coded Display**: Each unique chord gets its own color for easy visualization
- **🔤 Bilingual Support**: Works perfectly with both English and Persian (RTL) text
- **📱 Mobile-First Design**: Optimized for iPhone and iPad, works great on desktop too
- **💾 Local Storage**: All your data is saved locally in your browser
- **⚡ No Installation Required**: Works directly in any modern web browser
- **🎨 Beautiful Modern UI**: Clean, intuitive interface with smooth animations

## 🚀 Getting Started

### Using the App

Simply open the app in your browser and start creating songs!

**Live App**: https://mhmdcg.github.io/Chord/

### Add to iPhone/iPad Home Screen

1. Open the app in Safari
2. Tap the Share button
3. Select "Add to Home Screen"
4. The app will work like a native app!

## 📖 How to Use

### Creating a Song

1. Click **"+ New Song"** button
2. Enter the song title and artist (optional)
3. Paste or type the lyrics
4. Click **"Continue to Add Chords"**

### Adding Chords

1. Select any portion of text (can start/end mid-word)
2. A modal will appear - enter the chord name (e.g., Am, G, D7)
3. Click **"Save"** or press Enter
4. The text will be highlighted with a unique color
5. The chord name appears above the highlighted text

### Managing Chords

- **View Chord Legend**: See all chords used with their colors
- **Remove Chords**: Click on any highlighted text to remove its annotation
- **Edit Song**: Go back to edit lyrics or song details
- **Delete Song**: Remove songs you no longer need

## 🎨 Chord Color Palette

The app uses a carefully selected palette of 15 distinct colors that are easy to distinguish:
- Peach, Light Blue, Pink, Light Green, Misty Rose
- Khaki, Plum, Pale Turquoise, Light Pink, Pale Green
- Wheat, Thistle, Powder Blue, Peach Puff, Lavender

Colors cycle automatically if you use more than 15 unique chords.

## 💾 Data Storage

- All data is stored in your browser's **localStorage**
- Data persists across sessions
- **Important**: Clearing browser data will delete your songs
- **Backup**: Export your localStorage data periodically for safety
